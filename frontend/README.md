
# Frontend React (Vite + TS) — Estilo Apple / Paleta Café

## Variables de entorno
Crea `.env` en la raíz:
```
VITE_API_URL=http://localhost:8000
```

## Instalación
```bash
npm install
npm run dev
```

## Páginas
- Dashboard (KPIs simples)
- Clientes (buscar, crear, listar, eliminar)
- Técnicos (buscar, crear, listar, eliminar)
- Órdenes (crear, listar, eliminar)
- Mantenimientos (buscar, crear, listar, eliminar)
- Relaciones Mto–Técnicos (crear, listar, eliminar)

> Endpoints conectados 1:1 con tu backend FastAPI tal como los mapeamos.
